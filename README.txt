# For My Wife, Areeba ❤️

A romantic apology website made with HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js
- images/

## GitHub Pages
1. Upload all files/folders to your GitHub repository.
2. Go to Settings → Pages.
3. Select the main branch and `/root`.
4. Save and open the generated GitHub Pages URL.

## Optional music
Put a song named `music.mp3` next to `index.html`. The music button will play/pause it after a user click.
